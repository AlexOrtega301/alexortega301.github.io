# 📖 Blog Redirect – Alex Ortega

Este repositorio **no contiene código principal**, únicamente sirve como **redirect** hacia mi blog personal creado en **Microsoft Sway**.  
La idea es mantener un acceso rápido y sencillo desde GitHub Pages hacia el contenido del blog.

---

## 🌐 Blog en Microsoft Sway

El blog está alojado en **Microsoft Sway**, una plataforma que permite crear y editar presentaciones y páginas web de manera muy fácil.  
Gracias a Sway, el contenido del blog se puede actualizar sin necesidad de modificar directamente este repositorio.

---

## ⚙️ Funcionamiento

* Este repositorio actúa como **redirect** hacia el blog.  
* No contiene archivos complejos ni código adicional.  
* Se mantiene ligero y simple para que GitHub Pages apunte directamente al contenido deseado.

---

## 🚀 Propósito

El propósito de este repositorio es:

* Tener un acceso rápido al blog desde GitHub Pages.  
* Centralizar el contenido en un solo enlace.  
* Facilitar la edición del blog sin necesidad de modificar este repo.
